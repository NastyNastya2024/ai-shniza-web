3) Data flow for one Generate (arrows = data)
--------------------------------------------------------------------------------

  [prompt + media]
        │
        ▼
  Flask API ──► GenerationJob(status=queued)
        │
        ▼
  Dispatcher
        │  reads ChannelBinding[] + ChannelHealth
        │  writes RouteDecision
        │
        ├──► queue:replicate   payload_ref, upstream_ref
        ├──► queue:fal
        └──► queue:omniroute
                │
                ▼
           Channel Worker
                │  reads job
                │  calls upstream
                │
                ├──► Replicate prediction / fal queue / OmniRoute /v1
                │
                ▼
           GenerationJob(status=succeeded|failed)
                │  result_urls | reply | error
                │
                ├──► Postgres (metadata)
                └──► S3 (optional, bytes)
                │
                ▼
           Browser poll ◄── status + urls


4) Health / failover flow (control data)
--------------------------------------------------------------------------------

  Worker error/timeout
        │
        ▼
  ChannelHealth.error_streak++
        │
        ├── < threshold → channel stays healthy
        └── ≥ threshold → state=down, cooldown_until=now+T
                            │
                            ▼
                     Dispatcher (new jobs)
                            │
                            └── picks next ChannelBinding
                                (more traffic to fal / omni)
