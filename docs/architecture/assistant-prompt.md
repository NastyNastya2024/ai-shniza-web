# Ассистент Generate: роль и системный промпт

Дата: 2026-09-09  
Код: `CHAT_SYSTEM_PROMPT` + `_with_assistant_persona()` в `server.py`

--------------------------------------------------------------------------------
1. Зачем
--------------------------------------------------------------------------------

Ассистент в Generate — не «голая» LLM, а продуктовый агент
**«Заботливый Навигатор + Экономический Адвокат»**:

- помогает выбрать модель под бюджет и задачу;
- дорабатывает промпт под конкретную модель;
- подсказывает параметры запуска (видео / текст / image);
- держит этические границы (без насилия, суицида, экстремизма и т.п.).

Роль накладывается **независимо от бэкенд-модели**
(OmniRoute, DeepSeek на Replicate, Claude/GPT и др. из группы `assistants`).

--------------------------------------------------------------------------------
2. Куда вшито в коде
--------------------------------------------------------------------------------

| Путь | Как применяется промпт |
|------|-------------------------|
| `POST /api/chat` (UI: id=`assistant`, kind=`chat`) | `messages = [system: _build_chat_system_prompt(), ...history]` |
| Fallback чата → Replicate DeepSeek | тот же system+каталог склеивается в единый `prompt` |
| `POST /api/generate` для `group=assistants`, `kind∈{llm,chat}` | `_with_assistant_persona(user_prompt)` (= роль + каталог) |
| Image / video / audio generate | **не** накладывается (только генерация медиа) |

Env (чат):

- `OMNIROUTE_BASE_URL`, `OMNIROUTE_API_KEY`
- `OMNIROUTE_CHAT_MODEL` (по умолчанию `auto/coding:free`)
- `CHAT_FALLBACK_REPLICATE_MODEL` (по умолчанию `deepseek-ai/deepseek-v3.1`)

--------------------------------------------------------------------------------
3. Поток /api/chat (as-is)
--------------------------------------------------------------------------------

```
Browser (generate.html)
   │  POST /api/chat  { messages: [...] }
   ▼
Flask api_chat()
   │  + system = CHAT_SYSTEM_PROMPT
   ▼
OmniRoute /v1/chat/completions
   preferred → auto/coding:free → auto/best-free → auto/chat
   │
   │  при 4xx/5xx / недоступности
   ▼
Replicate DeepSeek (prompt = system + история)
   │
   ▼
JSON { reply, model, channel: omniroute|replicate }
```

--------------------------------------------------------------------------------
4. Содержание роли (сводка)
--------------------------------------------------------------------------------

Полный текст — константа `CHAT_SYSTEM_PROMPT` + динамический каталог
через `_build_chat_system_prompt()` в `server.py` (source of truth).

Кратко:

1. **Только каталог** — не рекомендует модели вне live `INTEGRATED_MODELS`
   (список + цены подмешиваются в system prompt на каждый запрос).
2. **Короткие ответы** — рекомендация ≤12 строк; `max_tokens≈420`,
   серверный `_compact_chat_reply` (~900 символов). Язык = язык пользователя.
3. **Структура** — запрет одного абзаца и утечек reasoning/CoT (английский meta).
4. **Не хватает данных** — всё равно сразу 1–2 ближайшие модели по действию и цене;
   не зацикливаться на уточняющих вопросах.
5. **Этика** — отказ от опасных тем; при подавленности — 8-800-2000-122 и
   https://www.iasp.info/suicidalthoughts/ , затем созидательная задача.
6. **Тон** — друг/наставник, без простыней и без смены языка.

Цены: `models_catalog/catalog.json` через `_integration_prices()`;
если цены нет — только относительные ярлыки, без выдуманных цифр.

--------------------------------------------------------------------------------
5. UI
--------------------------------------------------------------------------------

- Welcome в `generate.html` задаёт ожидание: задача, формат, бюджет на генерат.
- Выбор «Ассистент (OmniRoute)» → `/api/chat`.
- Выбор другого ассистента (DeepSeek, Claude, …) → `/api/generate` + persona wrapper.
