SEQUENCE — Generate с диспетчером, тремя очередями, failover
================================================================================

Участники (слева направо):

  U  = User / Browser
  A  = Flask API
  D  = Routing Dispatcher
  H  = Channel Health store
  Qr = queue:replicate
  Qf = queue:fal
  Qo = queue:omniroute
  Wr = worker-replicate
  Wf = worker-fal
  Wo = worker-omniroute
  R  = Replicate API
  F  = fal.ai
  O  = OmniRoute (:20128)
