3) Поток данных одного Generate (стрелки = данные)
--------------------------------------------------------------------------------

  [prompt + media]
        │
        ▼
  Flask API ──► GenerationJob(status=queued)
        │
        ▼
  Dispatcher
        │  читает ChannelBinding[] + ChannelHealth
        │  пишет RouteDecision
        │
        ├──► queue:replicate   payload_ref, upstream_ref
        ├──► queue:fal
        └──► queue:omniroute
                │
                ▼
           Channel Worker
                │  читает job
                │  вызывает upstream
                │
                ├──► Replicate prediction / fal queue / OmniRoute /v1
                │
                ▼
           GenerationJob(status=succeeded|failed)
                │  result_urls | reply | error
                │
                ├──► Postgres (метаданные)
                └──► S3 (опционально, байты)
                │
                ▼
           Browser poll ◄── status + urls


4) Поток health / failover (данные управления)
--------------------------------------------------------------------------------

  Worker error/timeout
        │
        ▼
  ChannelHealth.error_streak++
        │
        ├── < порог  → канал остаётся healthy
        └── ≥ порог  → state=down, cooldown_until=now+T
                            │
                            ▼
                     Dispatcher (новые job)
                            │
                            └── выбирает следующий ChannelBinding
                                (больше трафика на fal / omni)
