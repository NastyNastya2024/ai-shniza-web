# Фразы шарика на главной (`index.greet.*`)

Документ собирает **все пулы фраз**, которые когда-либо применялись к облачку яишенки на главной странице (`index.html` + `i18n/dict-ru.js` / `dict-en.js`).

## Как это работает сейчас

| Ключ / константа | Назначение |
|---|---|
| `index.greet.01` … `20` | Пул облачка |
| `index.say.hello` | Приветствие в сценарии (обычно = `greet.01`) |
| `GREET_INTRO_LAST` | Сколько первых фраз крутятся подряд при первом визите (сейчас `3`) |
| `GREET_REST_FIRST` … `GREET_REST_LAST` | Случайный пул после интро (сейчас `4`…`20`) |
| `GREET_INTRO_PAUSE_MS` | Пауза между интро-фразами (сейчас `6500`) |
| `localStorage aish-greeted` | После интро помечает «уже видели» |
| `startGreet()` | **Всегда** начинает с `greet.01` (привет + что это генератор); дальше интро только если ещё не `aish-greeted` |

Файлы: `i18n/dict-ru.js`, `i18n/dict-en.js`, логика — `index.html` (`greetLine`, `startGreet`, `chainIntro`, `pickGreetRest`).

Формат отображения: одна строка (`white-space: nowrap` у `#speech`), без `\n` в текстах.

## Не путать со студией

Фразы **студии** живут в `studio.eggy.*` (`app.html` → `intro()`), это отдельный пул. Сейчас в студии CTA моделей (P-Video / GPT Image 2 / Kling); на главной — пул **E**.

---

## Как вернуть старый пул

1. Скопировать нужную таблицу (A–E) в `i18n/dict-ru.js` / `dict-en.js` как `index.greet.01`…`20` и `index.say.hello`.
2. При необходимости выставить `GREET_INTRO_LAST` / `GREET_REST_FIRST` под длину интро (для A/B обычно `6` / `7`).
3. Для двух строк в облачке — `white-space: pre-line` и `\n` в строках; для одной строки — `nowrap` без `\n` (как сейчас).
